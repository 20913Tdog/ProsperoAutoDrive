The first release of Prospero AutoDrive. It shows the file system of a PS5 that runs a homebrew payload as a normal drive (`P:`) in Windows Explorer. The drive appears by itself when the PS5 is reachable and disappears when it is not.

Version 0.x: usable, tested on real hardware, but still early. Read the known limitations before you use it.

## What it does

- **`prospero-smbd.elf`** (PS5): an SMB2/3 server for the whole file system of the console, read and write, with NTLMv2 and mandatory signing. It is started from a file by a payload manager, also automatically at start (autoload).
- **`ProsperoAutoDrive.exe`** (Windows 11): its own installer and uninstaller, a tray icon with notifications. It finds the PS5, pairs once without a password to type, keeps the credentials in the Windows Credential Manager and connects the drive with the SMB client built into Windows. No driver, no third-party software, no administrator rights in operation.
- The drive is there within 3 s after the server becomes reachable. It is gone at once when the server ends in order, within 5 s on cable when the PS5 just disappears, and on Wi-Fi after about 13 s, so that short dropouts do not cut a copy.
- File times are correct even if the PS5's clock is off; the PC's time is the reference.

**Getting started:** [user guide](https://github.com/20913Tdog/ProsperoAutoDrive/blob/v0.1.0/docs/user-guide.md).

## Files

| File | Purpose |
|---|---|
| `ProsperoAutoDrive.exe` | the Windows program; start it to install |
| `prospero-smbd.elf` | the server for the PS5; goes into `/data/prospero-smbd/` |
| `SHA256SUMS` | the SHA-256 checksum of every file |
| `BUILD-INFO.txt` | version, the tested commit and the CI runs that built and released it |
| `LICENSE.txt` | MIT license of the Windows program and the repository |
| `LICENSE-ps5.txt` | GPL-3.0, the license of the PS5 server |
| `LICENSE-libsmb2-LGPL-2.1.txt` | LGPL-2.1 of libsmb2, which the server contains |
| `THIRD-PARTY-NOTICES.txt` | the third-party code in both programs and its licenses |
| `prospero-autodrive-0.1.0-source.tar.gz` | the complete source, including libsmb2 and our patches to it |

The two programs are byte for byte the files that were tested; the release only copies them from the tested build.

**Check a download** in a command prompt in the download folder:

```
certutil -hashfile ProsperoAutoDrive.exe SHA256
```

The result must equal the line for the file in `SHA256SUMS`.

## Known limitations

- The program is not signed: SmartScreen warns, and with Smart App Control turned on, Windows does not start it.
- The whole PS5 file system is shared read and write, without a protection list.
- The first PC that asks gets the password (and any PC in the 2 minutes after each server start, or in the 10 minutes after "Pair another PC"). The connection is signed, not encrypted.
- After the PS5 gets a new IP address, use "Search the network for PS5 (30 s)" in the tray menu.
- Explorer does not refresh by itself when files change on the PS5; press F5. No file locks.
- Windows 10 22H2 is best effort. The speed goal for 1.0.0 over Wi-Fi is not proven yet.

Details are in the [user guide](https://github.com/20913Tdog/ProsperoAutoDrive/blob/v0.1.0/docs/user-guide.md#7-known-limitations).

## Tested

On a real PS5 and a Windows 11 PC (evidence level E3), besides the automatic tests on every commit (E1 Linux, E2 real Windows SMB client):

- Discovery, pairing and heartbeat (P2.2, build `8e56644`, 2026-10-22); clock correction (P2.3, `aed080a`, 2026-10-22).
- Speed on cable, 7 alternating rounds of 1 GiB: writing 136 %, reading 101 % of the PS5's FTP server ftpsrv (`86e62c1`, 2026-10-24).
- CPU time when idle with a connected PC: below 0.1 % of one core on both sides (P30, `aef1906` and `b56cd09`, 2026-10-24).
- The drive on cable: there after 0.1 s, gone at once on an orderly end and about 3–4 s after pulling the cable, back at once (P3.2, `7eb440b`, 2026-10-24).
- 20,000 files in one folder, heartbeat at most 16 ms meanwhile (P34, `a6b7ca7`, 2026-10-25).
- Installation and removal in `C:\Program Files` and in a folder of one's own, without leftovers (P3.3, `b607a8d`, 2026-10-25).
- Ending the server from the tray, pairing with a reset server (`7f97ddc`, 2026-10-25), pairing again after a reinstall (`11b3c37`, 2026-10-25).
