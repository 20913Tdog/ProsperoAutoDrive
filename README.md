# Prospero AutoDrive

> **Status:** early development (0.x). Nothing in this repository is usable yet.

Prospero AutoDrive will make a PS5 running a homebrew payload show up as a regular network drive in Windows Explorer. The drive is connected automatically while the console is reachable and removed when it goes offline. Windows needs nothing but its built-in SMB client and one small program.

A full README follows once a first working draft exists.
